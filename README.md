# 지나트 외국어 (JINART BEAUTY Phrasebook)

지나트뷰티(부산 전포동)에서 중국인·일본인 손님을 응대할 때 바로 꺼내 쓰는 **실전 회화 웹앱**입니다.
설치 없이 브라우저로 열고, 아이폰 **Safari → 공유 → 홈 화면에 추가**하면 앱처럼 쓸 수 있습니다(PWA·오프라인 지원).

## 기능

- 🇨🇳 중국어 / 🇯🇵 일본어 원터치 전환 — 같은 카드가 선택한 언어로 바뀝니다.
- 8개 카테고리 88문장: 인사·예약 / 상담·디자인 / 시술 중 / 가격·결제 / 시술 후 주의 / 복습·패턴 / 실생활 / MZ·요즘 말
- 카드마다 **한국어 뜻 · 원문 · 병음(로마자) · 한국어 발음(소리나는 대로)** 을 함께 표시
- 🔊 발음 듣기 (Web Speech API, `zh-CN` / `ja-JP`, 0.75x 느리게·1.0x 보통)
- 📱 손님께 보여주기 — 큰 글씨 전체화면
- 🃏 플래시카드(뒤집기·이전/다음·즐겨찾기), 🎯 4지선다 퀴즈(뜻·듣기, 오답 다시 풀기), ★ 즐겨찾기, ✓ 학습 완료
- 학습 상태는 기기(localStorage)에 저장됩니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (UI + 회화 데이터 + 로직, 단일 파일) |
| `manifest.json` | PWA 매니페스트 (`지나트 외국어` / standalone) |
| `sw.js` | 오프라인 캐시 서비스 워커 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 참고

- 가격은 매장 기준값(속눈썹펌 4만 원, 눈썹 염색 3만 5천 원, 미인점 4만 원)이며, 아이라인·눈썹 시술은 "디자인 상담 후 안내" 표현으로 넣었습니다.
- 개인정보(연락처·주소 등)는 포함하지 않았습니다.
